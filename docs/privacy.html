TabFlow 隐私与数据说明

适用版本：1.3.1。个人开发者：deskid。联系邮箱：deskidzhou@gmail.com。

TabFlow 用于整理浏览会话，包括标签、原生标签组、书签和稍后读。普通管理与本地规则分类无需 Codex 或 API Key；可选模型能力有不同的数据处理路径。

标签、书签与稍后读

TabFlow 通过 Chrome API 读取标签标题、网址、窗口、分组及状态，展示和管理绑定窗口的标签，同时读取和管理浏览器的书签与稍后读。查看、搜索、关闭、移动、固定、静音及本地规则分组不需要把这些内容发送给模型服务。

扩展没有注入用于读取网页正文、表单或 DOM 的内容脚本；站点图标优先使用 Chrome 的 favicon 接口。扩展响应标签创建、更新、激活、移动和关闭事件，用于刷新界面和自动归类，不记录键盘输入、鼠标轨迹或上传点击流。搜索和选择等交互在功能中处理。

新安装默认使用本地规则，已有用户保留原分类引擎。自动归类按本地规则处理，可在设置中关闭。分组提示词是用户主动提供的偏好，会保存，使用模型时会交给对应模型。

可选模型与数据去向

模型分类使用待分类标签的 ID、标题、网址及分组提示词。

本地规则
在扩展内处理，不向模型服务发送分类内容。
Chrome 端侧模型
由 Chrome 在设备上推理，准备模型需要联网下载资源。可用性受 Chrome、设备、磁盘、网络、语言及模型状态影响，不保证所有设备可用；当前使用英文指令和组名，中文输入可能不受支持。
ChatGPT 订阅
用户自行在 OpenAI 登录并授权后，扩展直接请求官方模型目录与 Responses API，使用账号获准的 ChatGPT 计划；不经过开发者服务器，不继承本机 CLI 登录。
本机 Codex
通过单独安装的本机桥接交给官方 Codex CLI，再由 CLI 当前配置的模型服务处理，可能使用云端推理；本机桥接不等于离线。当前提供 Windows 安装脚本，其他系统未提供安装器。
OpenAI、DeepSeek、自定义 API
发送到用户选择的服务接口。第三方可能收费，其保存和使用请求的方式受该服务条款、政策和配置约束。

云端和 Codex 请求保留完整网址，包括 query 查询参数和 hash 片段。其中可能含个人搜索、内部路径、令牌或签名。TabFlow 不自动脱敏；标题及自定义提示词也可能包含个人或敏感内容。请只选择可信服务，并在使用前核对其政策。

除用户自愿登录 ChatGPT 时授权的基本账号身份信息外，TabFlow 不主动要求位置、支付或健康资料，但不能保证网址、标题或用户文本不含此类信息。没有开发者自己的服务器不意味着不处理用户数据。

自动清理与归档

自动清理默认关闭。启用 AI 模式后，扩展会在所有普通窗口中按保守、均衡或积极档定期分析并归档闲置标签，无需逐批确认；按时间模式不调用模型。预览会分析但不关闭页面。分组与 AI 清理共用所选 AI 引擎，更换模型会同时改变两者的数据去向。

本次浏览会话的标签网址、使用时间、激活次数、临时保护、判断缓存与当前预览清单（含标题、网址及判断结果）保存在 chrome.storage.session，浏览器会话结束后清除。AI 输入含候选及少量活跃主题上下文的标题、去除用户名、密码、query 和 hash 后的网址路径、组名与使用信号；这些字段仍可能敏感。保护网站和显式保护的标签、组不发给模型，不读取正文或表单。

清理配置、启用状态和网站保护保存在 chrome.storage.local，不参与同步。用户编辑的清理提示词保存在本机，并随 AI 请求发送给当前引擎。模型和密钥复用现有 chrome.storage.sync 设置，不另存清理副本；升级会移除旧副本。停用清理不删除共用模型设置，可在 AI 引擎设置中清空密钥。

归档在本机持久保存完整网址（含 query/hash）、标题、原窗口与组信息、时间、档位、模型名称、任务及原因。记录本身不发送给模型，不同步。可导出和删除；恢复成功后移除，失败保留。容量不足时停止新增归档，不按天数静默淘汰。卸载或清除扩展本地数据会删除记录；重新打开不保证恢复未保存输入。

设置、API Key 与同步

外观、自动归类开关、引擎、模型、接口地址、API Key 与分组偏好保存在 chrome.storage.sync。启用 Chrome 同步时，设置可能同步到账号关联设备。API Key 没有单独限制在本机保存，TabFlow 没有为其提供额外应用层加密。

每个提供商配置独立保留，切换引擎不会删除旧密钥。获取 API 模型目录时会将配置的密钥发送到所选接口，不发送标签内容；已授权接口的模型目录查询可能在打开对应设置时发生。分类请求会同时发送上述标签数据和提示词。

自定义接口按需请求对应协议和主机的访问权限；Chrome 授权覆盖该主机相同协议下的全部端口和路径。请求不携带浏览器 Cookie，并拒绝 HTTP 重定向。内置 OpenAI、DeepSeek 地址使用 HTTPS；自定义地址允许 HTTP，HTTP 没有传输加密。远程服务优先选择 HTTPS，不应把所有数据流描述为已加密。

ChatGPT 订阅授权原型

订阅路径通过 OpenAI 官方页面请求登录与计划推理授权，不读取本机认证文件、浏览器 Cookie 或其他应用凭据。扩展会接收并验证账号身份与授权凭据，用于模型目录和用户主动触发的分类。

Access、refresh、ID token 仅在 offscreen 文档承载的独立工作器内存中保留，不写入浏览器存储、不参与同步、不交给开发者。关闭设置、侧栏或独立窗口仍保持连接，各界面共享活动会话；完整结束 Chrome 进程、禁用或重载扩展会销毁该内存会话，之后需重新连接。账号标签、返回的邮箱、已验证的 subject、issued client ID 及本机 host UUID 保存在 chrome.storage.local，可通过清理扩展本地数据删除。

登录时按需请求 auth.openai.com、api.openai.com 与 127.0.0.1 的访问权限。临时跳转规则限定本次登录标签页和精确回调地址，在正常完成、取消、超时或授权标签页关闭时移除，不截获其他标签页的登录。已通过用户初次登录、模型目录与真实分类验证；长时间运行后的实际续期仍待验证。

在账户菜单退出会清除整个扩展的活动会话并尝试远端撤销；未确认撤销时会提示到 ChatGPT 设置中断开。关闭设置或侧栏不会退出，也不等于撤销官方授权。模型目录不代表实际推理权限或额度，请求不会自动改用 API Key 计费；Responses 设置 store=false，第三方保留仍以 OpenAI 政策为准。

本机 Codex 桥接

Codex 登录凭据由官方 CLI 管理，扩展不接收登录令牌或账号邮箱，只接收登录状态、认证类型、模型目录和分类结果。桥接不会直接把上游 RPC 错误正文送回界面，以减少暴露账号或配置内容的机会。

Windows 安装器为当前用户注册 Native Messaging Host，并在设备上生成启动器和清单。桥接仅允许安装清单中配置的扩展来源访问。生成文件含本机路径，不应提交到公开源码仓库。

使用范围与共享

TabFlow 仅将权限取得的数据用于浏览会话整理及直接相关功能。开发者不出售用户数据，不用于广告定向、信用评估、贷款判断或与功能无关的画像。

开发者没有独立的广告、统计或遥测后端，不会自动接收你的标签、密钥或提示词。为提供用户选择的分类功能，必要数据仍会传给相应模型服务；Chrome 同步也会处理配置。不能因此声明没有第三方传输。

第三方模型服务、Chrome 和 CLI 的处理依各自政策与配置而定。TabFlow 无法保证第三方不保留请求、不用于其自身模型改进或没有人工访问。我们不为广告目的提供数据，不授权对自动收集的浏览数据进行人工阅读。对你主动提供的技术支持材料，仅在授权范围内处理，或按法律及必要安全要求处理。

保存期限、访问与删除

  • 标签、标签组、书签与稍后读由 Chrome 管理，除上述清理会话状态及授权归档外，扩展不另建长期浏览历史数据库。保存书签、加入稍后读和修改分组的结果会保留到你自行修改／删除；卸载扩展不会自动恢复这些改动。
  • 分组结果及分组撤销状态主要在运行时内存中。正常分组撤销提示约 8 秒后释放，失败时可保留重试状态；清理归档另行持久保存，可从归档界面删除。
  • 设置、提供商配置、API Key 及提示词保留在 chrome.storage.sync，直至你修改或清除。同步副本、删除传播与卸载后的保留由 Chrome 及账号同步机制决定，不能保证卸载即清除全部副本。
  • 删除密钥请逐个切换曾使用的 API 引擎并清空 API Key；提示词和接口地址需分别修改。可在 Chrome 扩展管理撤销站点权限，并按 Chrome 数据与同步控制清理副本。到提供商处撤销密钥能阻止继续使用，但不会自动删除其既有日志。
  • 已传输给第三方的数据，保存期限和访问／删除请求依该服务政策处理，TabFlow 无法代删第三方日志。Chrome 模型资源由 Chrome 管理；CLI 认证、配置及本机 host 由 CLI 和独立安装管理，卸载扩展不等于卸载这些组件。
  • 主动发邮件或 GitHub 反馈时，你选择提供的联系方式和内容用于答复、排查，可保留于邮箱或 GitHub，直至问题结束且无继续保留必要或你提出删除。法律、安全和平台规则可能限制删除；没有自动定时清理承诺，公开内容可能已有第三方副本。
