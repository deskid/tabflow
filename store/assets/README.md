# 商店图片素材

| 文件 | 尺寸／格式 | 用途 |
| --- | --- | --- |
| [商店图标](icon128.png) | 128×128，RGBA PNG | 与上传包图标一致；主体在 96×96 安全区内 |
| [垂直标签](screenshot-01-tabs-1280x800.png) | 1280×800，RGB PNG | 标签、原生主题分组、固定与搜索入口 |
| [分组偏好](screenshot-02-settings-1280x800.png) | 1280×800，RGB PNG | 真实设置界面、可编辑分组预设与可选 API 配置 |
| [稍后读](screenshot-03-reading-1280x800.png) | 1280×800，RGB PNG | 稍后读条目、未读与已读状态 |
| [小推广图](promo-small-440x280.png) | 440×280，RGB PNG | 可选的商店推广图 |

三张截图以实际生产构建的 React 界面为基础，使用本地模拟 Chrome API 填入演示标签、书签和稍后读；不读取个人浏览器资料，不连接真实模型。截图保留真实控件与文字，不包含虚构的模型调用成功、评分、下载量或审核通过声明。标题与说明为宣传排版，截图内注明演示数据。

演示中的 example.com 子域是占位资料地址；Chrome、React、TypeScript 等链接仅用于展示公开开发资料。API Key 输入框里的 sk-… 是界面占位符，没有填写密钥。

上传截图按 01、02、03 排列。素材为整幅不透明 PNG，外缘方角，无额外外部留白。尺寸依据 [Chrome Web Store 图片要求](https://developer.chrome.com/docs/webstore/images)，提交时仍以后台实际要求为准。
