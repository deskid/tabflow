## 明确保留的三项延期

这三项是用户已决定保留的内部边界，不因准备商店材料或提交审核而擅自改代码，也不能包装成安全卖点。

1. **API Key 继续保存在 chrome.storage.sync**：随 Chrome 设置同步，没有额外应用层加密。清空需逐个引擎处理，切换 provider 不自动删除密钥。不得写成「仅本机」「端到端加密」或「密钥已安全隔离」。
2. **云端／Codex 继续使用完整 URL**：query/hash 保留，可能含搜索内容、内部路径或令牌，未自动脱敏。不得写成「只发域名」「已去敏」或「绝不发送私人信息」。
3. **云端分类响应完整标签 ID 校验延期**：当前云端 JSON 解析不等于与端侧／native 相同的完整校验。不得写成「所有模型输出均严格校验」「绝不会影响非目标标签」。

其他现有限制也需如实保留：自定义 HTTP 不提供网络传输加密；Native Messaging 是本机桥接，CLI 可能云端推理；端侧模型准备需联网，支持条件不保证全部设备。政策接受与否以实际审核为准，不承诺必过。
