## 单一用途（复制正文）

TabFlow 用于整理用户的浏览会话：在侧边栏或独立窗口查看和操作标签及原生标签组，并通过书签、稍后读、本地规则和用户主动选择的模型分类，帮助用户组织与继续浏览任务。

## 9 项必需权限理由（逐项复制）

| 权限 | 理由 |
| --- | --- |
| sidePanel | 在 Chrome 侧边栏显示当前浏览窗口的垂直标签、标签组、书签与稍后读管理界面。 |
| tabs | 读取标签标题、网址、窗口及状态，显示和搜索标签，支持切换、关闭、固定、静音、移动、复制、休眠及按用户选择分组；监听标签变化以同步界面和自动归类。 |
| tabGroups | 查询和修改 Chrome 原生标签组的名称、颜色、折叠状态及位置，实现整理、解散、自动归类和撤销分组。 |
| storage | 保存外观、自动归类开关、分类引擎、模型、接口地址、API Key 与分组偏好；使用 chrome.storage.sync，同步启用时可随 Chrome 账号同步。 |
| favicon | 通过 Chrome 扩展 favicon 接口显示标签、书签和稍后读条目的站点图标，帮助识别页面。 |
| bookmarks | 在会话整理界面读取、搜索、打开和删除书签，并按用户操作将标签组保存为书签文件夹。 |
| readingList | 在同一会话整理界面读取、添加、打开、删除稍后读条目并更新已读状态。 |
| contextMenus | 提供打开 TabFlow、将当前页面加入稍后读及触发同域名分组的右键入口。 |
| nativeMessaging | 仅为用户主动选择的 Windows 本机 Codex 高级集成，与单独安装的 com.tabflow.codex_bridge 本机程序通信，查询认证状态和模型目录并请求标签分类；普通管理与本地规则无需安装桥接。 |

兼容用户自选 OpenAI 兼容接口、OpenAI、DeepSeek 及本机 HTTP 接口。仅在需要时申请配置目标的协议和主机范围，不是安装时获得全部网站访问权。Chrome 匹配范围覆盖同主机相同协议的所有端口及路径。请求用于模型目录和分类，不注入网页正文读取脚本。HTTP 自定义接口不提供传输加密，建议仅用于可信本机服务，远程选 HTTPS。

## 远程代码

建议选择：**No**。由用户按最终上传包与后台实际定义确认后选择。

理由（复制正文）：

扩展的界面、分类调度和 Chrome 标签操作逻辑随安装包固定提供。云端或本机模型返回模型目录、组名、颜色和标签 ID 等 JSON 数据，由包内代码按固定行为解析和应用；不下载或执行远程 JavaScript，不用 eval 执行模型输出，也不把输出作为任意程序解释执行。Chrome 端侧模型资源由 Chrome 管理。可选 Windows Native Messaging Host 和官方 Codex CLI 是用户单独安装的本机程序，不是扩展运行时下载的脚本；本机 CLI 可通过自己的配置连接远端推理服务。

此理由不表示所有云端响应已完成完整标签 ID 校验；该项仍延期。

## 审核测试说明（复制正文）

TabFlow 用于整理浏览会话。请使用桌面 Chrome 120 或更新版本，在独立测试资料中打开少量公开页面。安装后点击工具栏图标打开侧边栏；新安装默认使用「本地规则」，基础路径无需账号、API Key 或 Codex。测试标签搜索、切换、固定、静音和临时标签关闭，点击「智能分组」检查规则整理及原生标签组同步；没有匹配页面时不保证创建组。可测试书签与稍后读、新标签自动归类开关、六种分组风格的选择／编辑／保存，以及产生新组后在约 8 秒提示期内撤销。风格预设供模型参考，本地规则不保证遵循提示词。

从普通窗口 A 打开独立 TabFlow 窗口，再切换至窗口 B；独立窗口应继续管理 A，关闭 A 后应停止标签操作并提示来源不可用。Chrome 端侧模型为可选能力，设备、语言及模型状态不支持时显示具体原因属于预期；准备模型需联网，推理在设备上进行。模型失败时请核对显示的错误和实际按域名处理结果，不将兜底当作模型成功。

OpenAI、DeepSeek、自定义 API 及 Windows 本机 Codex 为可选高级路径。模型分类可发送标签 ID、标题、完整网址及分组提示词，测试请仅使用公开页面。基础路径不依赖这些服务。当前未随本说明提供已验证的专用测试服务或凭据；若审核需要受保护功能，发布者须在非公开说明中补充专用、限额、可撤销测试访问、模型及有效期，不要求审核员使用私人密钥或账号。Windows 本机 Codex 需另外安装官方 CLI 和桥接；实际商店扩展 ID 为 pnjgkehmcfheoecnhenfeidkpkdjifkm，安装与验证细节见项目审核说明。
