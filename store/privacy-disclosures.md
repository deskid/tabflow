# 隐私实践与权限申报草稿

适用目标：TabFlow 1.1.0 中文公开发布。此文件供填写 Chrome Web Store 后台，不代替开发者本人作认证，也不保证审核结果。后台问题措辞、选项定义或最终代码发生变化时，必须重新核对。

## 单一用途（可粘贴）

TabFlow 用于整理用户的浏览会话：在侧边栏或独立窗口查看和操作标签及原生标签组，并通过书签、稍后读、本地规则和用户主动选择的模型分类，帮助用户组织与继续浏览任务。

## 数据类型建议

不能因为没有开发者自己的服务器，就选择「不处理任何用户数据」。扩展在本机读取数据，使用 Chrome 同步，并可向第三方接口传输数据。以下按数据的实际读取、保存和传输给出保守草稿；若后台仅针对离开设备的“收集”提问，仍应把 sync、远程 API 和 CLI 上游路径计入，再按其原文确认。

| 后台类型 | 建议 | 实际依据与填写边界 |
| --- | --- | --- |
| Web history／网络浏览记录 | 勾选 | 读取当前标签的网址、标题和相关标签状态，读取书签与稍后读中的网址。没有 history 权限，也不遍历历史记录库；这不排除当前访问网址属于此类型。模型分类可传输这些网址和标题。 |
| Website content／网站内容 | 建议勾选，后台实际定义需确认 | 标签标题、书签和稍后读标题是扩展处理的网页元数据，模型请求含标题；不读取页面正文、表单或 DOM。自定义分组提示词也属于用户提供内容，若后台将其归在网站内容中应包含。不能直接声明完全不处理网站内容。 |
| Authentication information／身份验证信息 | 勾选 | 用户填写的 API Key 用于模型目录和分类请求，以 Bearer 头发送到所选接口，并保存在 chrome.storage.sync。扩展不读取浏览器登录 Cookie，不接收 Codex 登录令牌或邮箱；仅接收 CLI 认证状态与类型等。 |
| User activity／用户活动 | 需按后台原文确认；若包括标签交互／状态则勾选 | 扩展响应标签创建、更新、激活、移动和关闭事件，用于刷新界面及自动归类，并处理选择、搜索、分组等用户操作；没有点击流、鼠标轨迹、键盘记录或行为分析上传。不能把未做遥测等同于未处理任何用户活动。 |
| Personally identifiable information／个人身份信息 | 通常不主动收集；需确认自由文本及网址的附带信息 | 无扩展账号注册，不主动要求姓名、邮箱、身份证等。完整网址、标题、自定义提示词可能含个人信息；用户主动发邮件或 GitHub 反馈时也会提供联系信息。若后台按可能包含的实际数据判定，需据此补选，不能将这些内容保证为匿名。 |
| Personal communications／个人通信 | 不主动读取；需确认后台定义 | 没有读取邮件或聊天正文的功能；私人页面标题、网址及用户自行填写提示词可能包含相关内容，需按后台定义判断附带内容。 |
| Financial and payment information／财务与支付信息 | 不主动收集；需确认后台定义 | 扩展不提供支付表单，不读取银行卡或交易正文。第三方模型的账单由提供商处理；不要据此声称第三方免费。附带在网址或用户文本里的敏感数据未被自动清除。 |
| Health information／健康信息 | 不主动收集；需确认后台定义 | 不读取健康记录正文或要求健康信息；网址、标题及用户文本可能附带敏感主题，不能保证自动排除。 |
| Location／位置 | 通常不勾选，按后台定义确认 | 不请求定位权限，不主动取得设备精确位置。第三方接口可从网络连接获得 IP，用户网址和提示词也可能包含地点；不宣称所有参与方均无法获知位置。 |

自定义提示词属于用户主动提供的分组偏好／内容，不应仅因它是文本输入就声称做键盘活动追踪；同时它会保存并可能发送给模型，不能漏报为“没有用户数据”。若后台提供 user-provided content／用户生成内容专门选项，按该项声明，并核对与 Website content 的对应关系。

## 数据用途和共享（可粘贴后按后台拆分）

数据仅用于显示和管理浏览会话、保存偏好、获取模型目录及执行用户选择的标签分类。普通管理和本地规则在扩展内处理；Chrome 端侧模型在设备上推理，模型准备需联网下载。用户选择 OpenAI、DeepSeek、自定义 API 或本机 Codex 后，标签 ID、标题、完整网址及分组提示词交给相应接口或 CLI 配置的模型服务。完整网址包含 query/hash，尚未自动脱敏。API Key 随模型目录和分类请求发送至配置的 API 服务，并通过 Chrome 设置同步机制保存。第三方保存和使用请求的方式取决于其配置、条款与隐私政策。

开发者没有独立数据收集、广告、统计或遥测服务器，不出售用户数据，不用于广告定向、信用评估或贷款判断。不要把这段说明缩写为“没有第三方共享”或“完全离线”。

## 权限理由（逐项填写）

以下以源代码功能为依据；最终权限数量需与上传包逐项核对。清单含 9 项必需权限，另有 HTTP/HTTPS 可选主机范围；本次不新增权限。

| 权限 | 可粘贴理由 |
| --- | --- |
| sidePanel | 在 Chrome 侧边栏显示当前浏览窗口的垂直标签、标签组、书签与稍后读管理界面。 |
| tabs | 读取标签标题、网址、窗口及状态，显示和搜索标签，支持切换、关闭、固定、静音、移动、复制、休眠及按用户选择分组；监听标签变化以同步界面和自动归类。 |
| tabGroups | 查询和修改 Chrome 原生标签组的名称、颜色、折叠状态及位置，实现整理、解散、自动归类和撤销分组。 |
| storage | 保存外观、自动归类开关、分类引擎、模型、接口地址、API Key 与分组偏好；使用 chrome.storage.sync，同步启用时可随 Chrome 账号同步。 |
| favicon | 通过 Chrome 扩展 favicon 接口显示标签、书签和稍后读条目的站点图标，帮助识别页面。 |
| bookmarks | 在会话整理界面读取、搜索、打开和删除书签，并按用户操作将标签组保存为书签文件夹。 |
| readingList | 在同一会话整理界面读取、添加、打开、删除稍后读条目并更新已读状态。 |
| contextMenus | 提供打开 TabFlow、将当前页面加入稍后读及触发同域名分组的右键入口。 |
| nativeMessaging | 仅为用户主动选择的 Windows 本机 Codex 高级集成，与单独安装的 com.tabflow.codex_bridge 本机程序通信，查询认证状态和模型目录并请求标签分类；普通管理与本地规则无需安装桥接。 |
| optional_host_permissions: http://*/* 与 https://*/* | 兼容用户自选 OpenAI 兼容接口、OpenAI、DeepSeek 及本机 HTTP 接口。仅在需要时申请配置目标的协议和主机范围；不是安装时获得全部网站访问权。Chrome 的匹配范围覆盖同主机相同协议的所有端口及路径。请求用于模型目录和分类，不注入网页正文读取脚本。HTTP 自定义接口不提供传输加密，不能声明所有流量均加密；建议用户仅将 HTTP 用于可信本机服务，远程选 HTTPS。 |

## Remote Code／远程代码

建议回答 **No**，前提是最终上传包继续与当前审阅行为一致，且后台对问题的实际定义相符。

可粘贴解释：扩展的界面、分类调度和 Chrome 标签操作逻辑随安装包固定提供。云端或本机模型返回模型目录、组名、颜色和标签 ID 等 JSON 数据，由包内代码按固定行为解析和应用；不下载或执行远程 JavaScript，不用 eval 执行模型输出，也不把输出作为任意程序解释执行。Chrome 端侧模型资源由 Chrome 管理。可选 Windows Native Messaging Host 和官方 Codex CLI 是用户单独安装的本机程序，不是扩展运行时下载的脚本；本机 CLI 可通过自己的配置连接远端推理服务。

该建议不等于所有返回数据已经完成全面校验。云端分类响应的完整标签 ID 校验仍延期，见内部提交检查。外部本机组件及模型 JSON 的政策定性最终由后台实际问题和审核决定；审核员可查阅配套源码和安装说明。

## Limited Use 认证与安全问题

由开发者本人阅读后台每条认证再选择，不能照草稿自动勾选。现有用途与广告／售卖限制的说明见 [隐私政策](../PRIVACY.md)。尤其要逐条检查：

- “不出售或转移数据，除允许用途外”的声明须包含为用户请求的分类而传给第三方服务的例外，不能声明绝不转移。
- 传输／存储加密问题不得直接选“全部已加密”：自定义 HTTP 受支持，API Key 没有应用层加密，sync 的实现由 Chrome 管理。本机 Native Messaging 与网络接口的政策适用条件不同；需按后台题目和官方要求评估，必要时先处理再提交。
- 若后台要求传输敏感数据前的显著披露／同意，核对最终产品界面的实际提示是否充分；商店介绍和隐私政策不能代替产品内要求。此材料不声称该项已经认证通过。
