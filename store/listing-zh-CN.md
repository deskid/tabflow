## 详细介绍（以下正文可直接粘贴）

TabFlow 帮助你整理当前浏览会话：在 Chrome 侧边栏查看垂直标签列表，把相关页面归入原生标签组，并集中访问书签和稍后读。

日常标签管理无需安装 Codex，也无需 API Key。新安装默认使用本地规则分类；已有用户保留原来的分类引擎设置。

主要功能

• 垂直查看和搜索当前窗口标签，切换、关闭、固定、静音或移动页面。
• 管理 Chrome 原生标签组：折叠、展开、修改名称和颜色，将组内标签保存为书签。
• 用本地规则或按域名整理标签，也可开启新标签自动归类。
• 智能分组后可在撤销提示出现期间恢复原分组；模型失败时会显示原因及实际采用的按域名处理结果。
• 在同一界面查找书签、管理稍后读，继续当前浏览任务。
• 打开独立窗口管理来源浏览器窗口，切换焦点后仍绑定原窗口。

按自己的方式分组

偏好设置提供「主题聚合」「项目任务」「使用场景」「资料类型」「站点服务」「极简收纳」六种分组提示词预设，可以继续编辑。预设供模型分类参考；本地规则按内置规则运行，不保证遵循自定义提示词。

可选模型能力

• Chrome 端侧模型：支持时在设备上执行分类，准备模型需要联网下载资源。是否可用取决于 Chrome 版本、设备、语言及模型状态，并非所有设备都支持；当前使用英文指令和英文组名，中文输入可能受模型语言支持限制。
• OpenAI、DeepSeek 或自定义 OpenAI 兼容 API：自行配置服务、模型及所需密钥；第三方服务可能收费。
• Windows 本机 Codex：面向高级用户的可选集成，需单独安装本机桥接、官方 Codex CLI 并完成其认证或提供商配置。本机桥接可能调用云端模型，不代表离线推理。当前提供 Windows 安装脚本，未提供其他系统安装器。

快速开始

1. 安装后点击工具栏 TabFlow 图标打开侧边栏。
2. 直接管理标签，或点击「智能分组」使用默认本地规则。
3. 需要模型分类时，在偏好设置选择引擎，完成可用性检测、下载或接口授权，再返回整理。

隐私与数据

普通标签管理和本地规则分类不需要把标签内容发送给模型服务。TabFlow 不注入读取网页正文的内容脚本，没有独立的广告、统计或遥测后端。

选择云端 API 或本机 Codex 分类时，待分类标签的 ID、标题、完整网址（包括 query 查询参数和 hash 片段）及分组提示词会交给所选服务或 CLI 配置的模型服务。网址与提示词可能包含私人内容，请在使用前检查，并阅读相应提供商政策。获取 API 模型目录会发送配置的密钥，但不发送标签内容。

外观、引擎配置、分组偏好及 API Key 保存在 chrome.storage.sync；启用 Chrome 同步时可能同步到账号关联设备。TabFlow 没有对密钥增加应用层加密。切换引擎不会清除旧密钥，可分别进入各引擎清空。自定义接口按需请求对应主机访问权限。
